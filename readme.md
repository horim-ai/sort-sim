# 🏁 정렬 레이스 (Sort Race)

**고등학교 정보 수업 도입용 정렬 알고리즘 시각화 시뮬레이터**

> 버블 정렬, 선택 정렬, 삽입 정렬이 데이터를 비교하고 교환하는 과정을 실시간 막대그래프 애니메이션과 카운터로 직관적으로 체험할 수 있는 교육용 웹 애플리케이션입니다.

---

## 🎯 기획 의도 및 학습 목표
* **대상**: 고등학교 1학년 정보 (단원: 알고리즘과 프로그래밍 - 정렬 알고리즘)
* **수업 장면**: 수업 도입 단계 (약 5~10분, 호기심 유발 및 직관적 이해)
* **학습 목표**:
  1. 정렬 알고리즘마다 데이터를 비교하고 교환하는 동작 방식의 차이를 시각적으로 구분할 수 있다.
  2. 데이터 개수와 초기 정렬 상태에 따라 알고리즘의 효율성(비교·교환 횟수)이 크게 달라짐을 발견할 수 있다.

---

## ✨ 주요 기능

### 1. 실시간 시각화 및 카운터 (결과 영역)
* **막대그래프 애니메이션**: 데이터의 크기(높이)와 현재 상태를 색상으로 즉시 구분합니다.
  * 🟦 **파란색**: 기본 상태
  * 🟨 **노란색**: 현재 크기를 비교 중인 두 원소
  * 🟥 **빨간색**: 자리 교환(이동)이 일어나는 원소
  * 🟩 **초록색**: 정렬이 완료된 원소
* **실시간 카운터**: 알고리즘이 수행하는 **총 비교 횟수**와 **총 교환(이동) 횟수**를 대형 숫자로 실시간 집계합니다.

### 2. 직관적인 조작 인터페이스 (조작 영역)
* **정렬 알고리즘 선택**: 버블 정렬, 선택 정렬, 삽입 정렬
* **데이터 개수 조절**: 슬라이더를 이용해 5개 ~ 30개 범위 내에서 조절
* **초기 배열 상태**: 🎲 무작위 / 📈 이미 정렬됨 / 📉 역순 정렬됨
* **재생 속도 조절**: 🐢 느리게 / 🚶 보통 / ⚡ 빠르게 (애니메이션 실행 중에도 실시간 변경 가능)

### 3. 원리 및 탐구 과제 패널 (원리 영역)
* 선택한 알고리즘의 핵심 동작 규칙 요약 제공
* 학생들이 직접 조작하며 답을 찾는 **수업용 탐구 과제 2종** 수록
* 실제 컴퓨터 구현과의 차이점(**단순화한 부분**: 1~N까지의 중복 없는 고유 자연수 사용) 안내

## 🚀 실행 및 배포 방법

### 1단계: 단일 HTML 파일로 바로 실행 (현재 버전)
별도의 설치나 서버 구축 없이 `index.html` 파일을 웹 브라우저(Chrome, Edge, Safari 등)로 열기만 하면 즉시 동작합니다.
* 모바일(스마트폰) 화면과 교실 전자칠판/프로젝터 환경 모두에 최적화되어 있습니다.

### 2단계: 향후 확장 계획
* **Vite + React** 기반 프로젝트로 구조화
* 서버 코드 및 데이터베이스 없는 순수 프론트엔드 정적 웹앱 유지
* **GitHub** 저장소 연동 후 **Vercel**을 통한 무료 웹 배포
